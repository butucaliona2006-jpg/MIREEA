# MIREA – Magazin Online de Haine

## Descriere proiect
**MIREA** este un magazin online modern de haine creat în cadrul disciplinei **Tehnologii Web (TWeb)**.  
Proiectul respectă cerințele celor 5 laboratoare obligatorii:

- Laborator 1 – HTML
- Laborator 2 – CSS
- Laborator 3 – JavaScript
- Laborator 4 – PHP
- Laborator 5 – AJAX

Scopul proiectului este realizarea unui site web complet funcțional, minimalist și estetic pentru un brand fashion premium.

---

## Concept
Brandul **MIREA** promovează:
- stil minimalist
- eleganță
- design modern
- experiență intuitivă pentru utilizatori

---

## Funcționalități principale

### HTML:
- structură semantică completă
- pagini multiple:
  - Home
  - Shop
  - About
  - Contact
- formulare
- navigare

### CSS:
- design responsive
- layout Flexbox/Grid
- animații hover
- stil minimalist premium
- navbar sticky

### JavaScript:
- coș de cumpărături (localStorage)
- căutare produse live
- actualizare dinamică coș
- validare interactivă

### PHP:
- procesare formular contact
- conectare la baza de date MySQL
- salvare mesaje utilizatori

### AJAX:
- căutare fără refresh
- abonare newsletter
- interacțiuni dinamice
